# BookBinge - Hybrid Book Recommendation System
A Hybrid Book Recommender System built using Python, Machine Learning, HTML, and similarity scores, combining collaborative and content-based filtering to deliver smarter and more personalized book suggestions.
<br>
<br>
<h2><b>🚀 Features</b></h2>

<br>
✨ Hybrid recommendation approach (Content + Collaborative)
<br>
✨ Uses cosine similarity for accurate matching
<br>
✨ Precomputed similarity stored using .pkl files for faster response
<br>
✨ Interactive web interface using HTML
<br>
✨ Lightweight, fast, and beginner-friendly deployment
<br>
✨ Personalized recommendations based on user input
<br>
<br>
 <h2><b>🧠 Tech Stack<b></h2>
<br>
🐍 Python – Core backend logic
<br>
📊 Pandas & NumPy – Data processing
<br>
🤖 Scikit-learn – ML similarity calculations
<br>
📦 Pickle (.pkl) – Model & similarity storage
<br>
📐 Cosine Similarity – Recommendation engine
<br>
🌐 HTML5 – Frontend structure
<br>
🎨 CSS3 – UI styling
<br>
🔥 Flask – Web framework 
<br>
🗄️ Jupyter Notebook – Model training & experiments
<br>
💾 Git & GitHub – Version control
<br>
<br>
<h2><b>📊 Dataset</b></h2>
<br>
The system uses a book dataset containing:
<br>
